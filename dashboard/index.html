snapshot model
How the implied value is built. implied = TVL × category multiple × momentum × patience × reach The category multiple is the median market cap over TVL that protocols of the same category already trade at, measured from the live-token side of this same snapshot; a category with fewer than three such protocols borrows the whole live field's median. Momentum is the seven-day TVL change, patience is how long the protocol has run with no token of its own, and reach is how many chains it is on.
Every figure comes from the sealed DefiLlama snapshot written beside this page; nothing is fetched, and no protocol is listed or ranked by name. An implied value is a model's claim, not a promise, and not make.fun's.
